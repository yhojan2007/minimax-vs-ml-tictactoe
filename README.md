## 📖 Descripción

Este proyecto implementa el clásico juego **Tres en Raya (Tic-Tac-Toe)** con tres modos de juego:

1. **Humano vs Humano** — Dos jugadores en la misma máquina.
2. **Humano vs IA Minimax** — IA perfecta que explora el árbol de estados con Backtracking.
3. **Humano vs IA Machine Learning** — IA que aprende de Minimax mediante un Árbol de Decisión.

El objetivo pedagógico es demostrar cómo un modelo de **Machine Learning** puede **aproximar** la lógica de un algoritmo de búsqueda exhaustiva, reemplazando la exploración recursiva por **inferencia instantánea**.

---

## 🎯 Objetivos de Aprendizaje

- ✅ Estructurar software complejo con el patrón **Modelo-Vista-Controlador (MVC)**.
- ✅ Representar espacios de estados mediante **árboles implícitos y explícitos**.
- ✅ Implementar **Backtracking** para exploración y retroceso de decisiones.
- ✅ Desarrollar el algoritmo **Minimax** para juegos de suma cero.
- ✅ Generar **datasets sintéticos** a partir de simulaciones.
- ✅ Entrenar un **DecisionTreeClassifier** con Scikit-Learn.
- ✅ Comparar rendimiento: **precisión** vs **latencia**.
